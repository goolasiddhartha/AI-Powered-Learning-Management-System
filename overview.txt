==================================================
2. PROJECT OBJECTIVE
==================================================

Build a Learning Management System where:

1. Admins manage users, roles, courses, and the overall platform.
2. Instructors create and manage courses and lessons.
3. Students enroll in courses and learn through lessons.
4. Students can take quizzes and track their progress.
5. The system stores student activity and performance.
6. Generative AI provides intelligent learning assistance.

==================================================
4. ROLE-BASED ACCESS CONTROL
==================================================

Implement Role-Based Access Control.

The backend must never trust the frontend role.

The frontend can hide UI elements, but the backend must independently verify permissions.

For example:

Student must NOT be able to call:

POST /courses

Instructor can call:

POST /courses

Admin can manage all courses.

An instructor should normally only be able to modify courses that they own.

Create reusable authorization logic.

Example:

require_role("ADMIN")

require_role("INSTRUCTOR", "ADMIN")

require_role("STUDENT")
